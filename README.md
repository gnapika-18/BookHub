
# 📚 BookHub – Book Discovery and Reading Management

BookHub is a React-based web application that allows users to explore books, search for their favorite titles, and manage their reading activities.

## 🚀 Features

- User Registration and Login
- Form validation and error messages
- Protected routes for authenticated users
- Book browsing and searching
- Filter books by categories and ratings
- Mark books as Read
- Manage Ongoing Books
- Custom 404 Page Not Found
- Responsive user interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Router DOM
- Local Storage
- Google Books API
- Git and GitHub

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/gnapika-18/BookHub.git
   ```

2. Navigate to the project folder:

   ```bash
   cd BookHub
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 🔐 Authentication Note

This project currently uses browser Local Storage for demonstration purposes. It does not implement backend authentication.
